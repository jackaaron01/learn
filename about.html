02 / 添加内容

三步发布一篇新笔记

  1. 1
    放入文档目录

    将 .md 文件放进仓库的 documents/，可用子文件夹整理主题。

  2. 2
    提交并推送

    推送到 main 分支，阅读器会自动发现新增文档。

  3. 3
    打开网页阅读

    部署更新后刷新阅读器；新文章会出现在文档列表中。

cp 我的笔记.md documents/
git add documents/
git commit -m "add a note"
git push origin main
